\# Mi primer agente IA



Proyecto de aprendizaje para construir un agente conversacional con Python y OpenAI Agents SDK.



\## Funcionalidades



\- Chat interactivo desde terminal.

\- Memoria durante la sesión.

\- Configuración de API mediante archivo `.env`.

\- Ejecución dentro de entorno virtual Python.



\## Requisitos



\- Python 3.10 o superior

\- Git

\- Una API key de OpenAI



\## Instalación



Clonar el repositorio:



```bash

git clone https://github.com/nicodonosocp-web/mi-primer-agente.git

cd mi-primer-agente
